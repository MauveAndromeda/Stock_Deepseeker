# Examples

Simple, working examples of how to use Stock Deepseeker.

## ⚠️ Important

These are **educational examples**, not production-ready code. They demonstrate:
- Basic usage patterns
- API structure
- Core concepts

**What these examples are NOT:**
- Production trading systems
- Optimized code
- Complete implementations

## Available Examples

### basic_backtest.py
Simple moving average crossover strategy using the event-driven backtest engine.

**Status:** Skeleton implementation
**Shows:** Strategy structure, backtest configuration

```bash
python examples/basic_backtest.py
```

## Usage

1. Install dependencies:
```bash
pip install -e .
```

2. Run an example:
```bash
python examples/basic_backtest.py
```
